# Piyush Kumar — Portfolio

Personal portfolio of Piyush Kumar, a full stack developer at Airbus. Live at **[piyushdev2108.netlify.app](https://piyushdev2108.netlify.app)**.

Built with Next.js 15, React 19, TypeScript, Tailwind CSS and Framer Motion, and deployed on Netlify.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Editing content

All copy lives in [`data/index.ts`](data/index.ts): the about grid, tech stack, projects, experience and social links. The downloadable resume is [`public/Piyush_Kumar_Resume.pdf`](public/Piyush_Kumar_Resume.pdf).
